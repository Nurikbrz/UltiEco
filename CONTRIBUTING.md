# Contributing to UltiEco

UltiEco is in its design phase. Suggestions, compatibility research and accessibility feedback are welcome.

**Before external code contributions:** choose a source license and publish a concrete contribution process. Public visibility is not a substitute for a license.

When proposing an issue, describe:

- The device and operating system involved
- The problem you want solved
- The expected user experience
- Platform permissions and security/privacy concerns
- How the feature might fail or be unsupported

Future code contributions should include tests for protocol parsing and permission checks and should never include private keys, credentials or unauthorized remote-control features.
